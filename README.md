<summary>🇷🇺 <b>Русская версия (Основная)</b></summary>

**Pulse Pad** — это компактный локальный сервер. Он нужен для того, чтобы в один клик выводить интерфейс модов на экран твоего телефона или планшета по домашней сети Wi-Fi.

> ⚠️ **Дисклеймер:** Я **не являюсь** автором оригинальных модов. Эта утилита создана исключительно для удобства игроков, чтобы избавить их от ручной настройки IP-адресов, портов и возни с консолью.

### 📦 Требуемые моды (Steam Workshop)
Перед использованием убедись, что у тебя установлены:
1. [PZ Pulse (Status Panel)](https://steamcommunity.com/workshop/filedetails/?id=3753700423)
2. [PZ Map (Global Map)](https://steamcommunity.com/sharedfiles/filedetails/?id=3770149036)

### 🛠 Инструкция по запуску
1. Скачай `Pulse.Pad_0.1.0_x64-setup.exe` (или Portable-версию) из раздела [Releases](https://github.com/Vlaseeds/Pulse-Pad/releases/latest).
2. Запусти утилиту. Она автоматически просканирует твои диски и найдет нужные папки модов.
3. **Если автопоиск не сработал** (например, моды лежат на нестандартном диске), укажи пути вручную:
   * *Путь к Pulse:* `.../Steam/steamapps/workshop/content/108600/3753700423/mods/PZ_Pulse/42/media/web`
   * *Путь к Map:* `.../Steam/steamapps/workshop/content/108600/3770149036/mods/PZ_Map/42/media/web`
4. Нажми **"Запустить"**, наведи камеру телефона на появившийся QR-код — и всё готово.

### 🛡 Важно: Антивирус и SmartScreen
Так как это инди-софт без платного корпоративного сертификата, Windows может выдать окно с угрозой `Wacatac.C!ml`. Это ложное срабатывание из-за того, что программа лезет в автозагрузку и поднимает веб-сервер. Код полностью чист и открыт здесь, на GitHub. При запуске просто нажми *«Подробнее» -> «Выполнить в любом случае»*.

<summary>🇬🇧 <b>English Version</b></summary>

**Pulse Pad** is a lightweight local server designed to easily stream mod interfaces to your phone or tablet screen over your home Wi-Fi network.

> ⚠️ **Disclaimer:** I am **not** the author of the original mods. This utility was created strictly for convenience to save players from manually configuring IP addresses and ports.

### 📦 Required Mods (Steam Workshop)
Make sure you have subscribed to these mods before using the app:
1. [PZ Pulse (Status Panel)](https://steamcommunity.com/workshop/filedetails/?id=3753700423)
2. [PZ Map (Global Map)](https://steamcommunity.com/sharedfiles/filedetails/?id=3770149036)

### 🛠 How to Use
1. Download `Pulse.Pad_0.1.0_x64-setup.exe` (or the Portable version) from the [Releases](https://github.com/Vlaseeds/Pulse-Pad/releases/latest) section.
2. Launch the utility. It will automatically scan your drives to find the mod directories.
3. **If auto-detect fails** (e.g., mods are on a custom drive), set the paths manually:
   * *Pulse Path:* `.../Steam/steamapps/workshop/content/108600/3753700423/mods/PZ_Pulse/42/media/web`
   * *Map Path:* `.../Steam/steamapps/workshop/content/108600/3770149036/mods/PZ_Map/42/media/web`
4. Click **"Start"**, scan the QR code with your mobile device, and you're good to go.

### 🛡 Important: Antivirus & SmartScreen
Since this is indie software without a paid certificate, Windows might throw a `Wacatac.C!ml` warning. This is a false positive because the app registers in startup and hosts a local server. The code is fully open-source here on GitHub. Simply click *«More info» -> «Run anyway»*.
